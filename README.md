Budget Rumah Tangga — alat pengelola keuangan keluarga Indonesia (Rupiah) yang benar-benar jalan: beranda ringkasan (pemasukan Rp 8.650.000, pengeluaran Rp 5.563.000, sisa Rp 3.087.000 untuk November 2026), catat transaksi (tambah/ubah/hapus, langsung memperbarui total, chart, dan progress bar), anggaran per kategori dengan progress bar dan peringatan, laporan dengan chart canvas (tren 5 bulan, perbandingan dengan bulan lalu), target tabungan, dan tips hemat. Semua perhitungan konsisten karena dihitung dari satu sumber data; perubahan tersimpan di localStorage. Situs statis tanpa build step dan tanpa network request: chart digambar dengan canvas polos, navigasi memakai hash routes, dan layout berjalan di desktop maupun phone.

## Run it

```sh
node serve.ts
# buka http://localhost:8080
```
